# APRENDE LIAN JAPAUN

Aplikasaun Android ba aprende lian Japonês ho interface Tetun.

## Prinsípiu
- Offline-first
- JLPT: N5 → N4 → N3 → N2 → N1
- Vokabuláriu, Kanji, Gramatika, Partíkula, Konversa, Rona, Teste no Progresu
- Komunidade: ありがとう友達 / ARIGATOU TOMODACHI

## Build
Importa pasta ida-ne'e iha Android Studio no sincroniza Gradle. Depois bele halo APK/AAB ba teste.
